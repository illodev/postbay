A request for changes can become a new version without anyone’s hands. Signed webhooks wake an agent runner; the agent works through the comments, uploads the next version and answers each one: fixed, cannot do, or needs a person.

One Docker Compose file runs it all: the app, a worker, PostgreSQL, S3-compatible storage and automatic TLS. Your files and your accounts never leave your machine.

Read the deployment guideGitHub
$ git clone https://github.com/illodev/postbay.git && cd postbay
$ cp deploy/.env.example deploy/.env   # your domains and secrets
$ docker compose -f deploy/docker-compose.yml \
    --env-file deploy/.env up -d --build
